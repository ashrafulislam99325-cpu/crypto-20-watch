CRYPTO 20 WATCH — INSTALLABLE PWA

ফোনের Home Screen-এ অ্যাপ হিসেবে রাখতে:

১) ZIP Extract করুন।
২) Extract করা Crypto20WatchPWA ফোল্ডারের ভেতরের সব ফাইলসহ পুরো ফোল্ডারটি HTTPS hosting-এ প্রকাশ করুন।
   সহজ উপায়: Netlify Drop-এ ফোল্ডারটি upload করুন (প্রয়োজনে Netlify account লাগতে পারে)।
৩) প্রকাশিত https:// ওয়েবসাইটটি Android Chrome-এ খুলুন।
৪) Chrome-এর ⋮ মেনু > Install app / Add to Home screen চাপুন।
   যদি পেজে Install App বোতাম দেখা যায়, সেটিও ব্যবহার করতে পারেন।
৫) ইনস্টল হওয়ার পর Home Screen-এর Crypto 20 আইকনে চাপলে standalone app-এর মতো খুলবে।

গুরুত্বপূর্ণ:
- PWA ইনস্টল করতে HTTPS hosting আবশ্যক; শুধু content:// বা file:// থেকে পূর্ণাঙ্গ PWA install হয় না।
- অ্যাপের মূল UI offline-এ খোলা যাবে; লাইভ দাম ও alert পরীক্ষা করতে ইন্টারনেট এবং অ্যাপ খোলা থাকা দরকার।
- Price data CoinPaprika public API থেকে আসে; আপডেট তাৎক্ষণিক নাও হতে পারে।
- এটি শুধু tracking tool, কেনাবেচা বা investment advice নয়।
